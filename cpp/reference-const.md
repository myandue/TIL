# C++ 참조 & const

## 참조(reference)
- 값을 copy하는 것이 아니라 해당 주소를 읽는 꼴인것이다.
- `int& b = a;` : 변수 b에는 a의 주소가 할당됨
- 한 번 정하면 대상 변경 불가. 
    ```
    int a = 5, c = 100;
    int&b = a;
    b = c; // => 여기서 a의 값은 100이 된다.
    ```


## 값 전달 vs 참조 전달
- 값 전달 `int b = a`: b에 a의 값을 복사해서 붙여넣는것이다. b를 변경해도 a에는 영향이 없다.
- 참조 전달 `int& b = a`: b에 a의 주소를 대입한다. 때문에 b를 변경하면 a의 값도 변경된다.
- 참조를 쓰는 이유
    - 원본 변경
    - '복사'의 경우 원본이 크다면(string, vector, 클래스) 복사하는데에 비용이 많이 들게된다. 그래서 아예 주소를 바라봄으로써 원본에 직접 접근하는 것이다.

## const
- `const`는 불변의 값에 붙인다.
- `const int x = 5;`: 여기서 x는 상수가 된다. x에 다른 값을 대입시킬 수 없다.

## const 참조 (const T&)
- 참조해서 직접 접근함으로써 copy 비용을 없앤다.
- const를 붙여줌으로써 원본 변경을 방지할 수 있다.
- 원본을 수정하려는 목적이 아니라 빠르게 값을 가져다 쓰기 위해 참조의 형태로 접근을 하되, 원본은 보호할 수 있게된다.

## const 참조를 쓸 때
- 작은 값(int, double)을 가져다 쓸 때는 차라리 copy하는 형태가 낫다. (주소를 통해 찾아가는 비용이 있기 때문)
- 큰 객체(string, vector, 클래스)들을 가져다 쓰고자 할 때 사용한다.
