# 스택 vs 힙 메모리

## 메모리
- 프로그램 실행 -> OS가 해당 프로그램에 메모리 한 덩어리 부여 -> 해당 메모리를 스택/힙 등으로 구획을 나눔

## 스택 (자동)
- 함수 호출에 묶인  LIFO 구조 (프레임 push/pop)
- 지역 변수가 해당 메모리에 보관됨
- 스코프가 끝나면 자동으로 정리됨
- 빠르지만 크기 제한이 있음
- LIFO(Last In First Out): 나중에 부른 함수가 먼저 끝남

## 힙 (수동)
- 자유 메모리 풀 (관리자가 빈자리를 찾아줌)
- `new`로 할당
- 수동으로 정리해야함. 하지 않으면 메모리 누수(창고가 꽉 참).
- 수명 스코프에 묶이지 않아 생명주기가 길다.
- 순차적으로 쌓이는 것이 아니라 자유 창고이기 때문에 느리지만 크기가 큼.

## 선택
- 스코프 안에서만 쓸거면 스택메모리를 사용
- 스코프 밖에서도 사용해야한다면 힙메모리를 사용
