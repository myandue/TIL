# 포인터 & 참조

## 포인터
- 주소를 담는 변수
- `&x`: x의 주소값 / `*p`: 해당 포인터가 가리키는 주소에 보관된 실제 값
- `p->멤버` = `(*p).멤버`: 포인터 p가 가리키는 주소에 보관된 실제 값.의 멤버.

## 참조 vs 포인터
| | 참조 | 포인터 |
|---|---|---|
| 정체 | 별명(=원본) | 주소 담은 변수 |
| 값 접근 | `r` | `*p` |
| 재지정 | 불가 | 가능 |
| null | 불가 | 가능(nullptr) |
- 포인터를 쓰는 이유: null 표현 / 재지정 / 힙 관리
