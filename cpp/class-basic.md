# C++ 클래스 기초

## Class
데이터 + 함수를 한 덩어리로 묶은 것

## 생성자 · 소멸자
- 생성자: 객체 만들 때 자동 실행
- 소멸자(~): 객체 사라질 때 자동 실행 // 자원 관리를 용이하게 해준다. (RAII)
- 소멸자를 직접 호출하지 않더라도, 스코프를 벗어나면 자동으로 실행된다.

## 접근 제어 (public / private)
- `public:` / `private:` : "여기서부터 이 규칙"이라는 구간 라벨
- class는 기본적으로 private이다

## RAII
- 생성자에서 자원 획득, 소멸자에서 반납
- 소멸자가 자동 실행되어 반납을 잊는 것을 방지할 수 있다. -> 소켓·락·메모리 자동 정리 보장

## 스코프 & 변수 종류
- 스코프: 변수가 사는 범위 (선언된 { }). 해당 구역을 벗어나면 호출할 수 없다.
- 지역 변수: 함수 소속.
- 멤버 변수: 클래스 소속. 여러 함수가 공유.

## etc.
- auto
    - 타입 자동 추론
    - 동적 변수는 아님. 컴파일 시점에 고정.
    - ex.
        ```
        // auto 쓸 때
        auto end = std::chrono::steady_clock::now();

        // auto 안 쓸 때
        std::chrono::steady_clock::time_point end = std::chrono::steady_clock::now();
        ```
- endl
    - 줄바꿈 + flush <- 즉시 출력
    - "\n" <- 줄바꿈만. flush 안 함. 
    - endl은 매번 버퍼를 비우는 것이기 때문에 약간 느리다. 때문에 실무에서는 평소엔 `\n`을 쓰고, 정말 즉시 출력해야할 때만 `flush` 하는 게 정석이다.
